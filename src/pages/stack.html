Stack

The components Aevia is made of, and the reason each one is there.

ComponentRoleWhy this one
OpenTofuServer, firewall, DNS, tunnel, bucketsInfrastructure is reviewed as a plan before anything changes; the open-source fork keeps the licence simple.
k3sKubernetes on one nodeSmall enough for a single server, and a real cluster API for everything that follows.
CiliumNetworking and isolationDefault-deny between namespaces, and flow visibility with Hubble.
Argo CDGitOps deliveryThe cluster pulls the desired state, so a push is the deploy and drift heals itself.
SOPS and ageSecrets in GitEncrypted at rest in the repository, decrypted only inside the cluster.
Cloudflare Tunnel and AccessPublic edge and sign-inNo inbound web port on the server; private tools are behind a login.
AuthentikSingle sign-onOne identity for Cloudflare Access, Grafana and Argo CD, with passkeys.
TraefikIngressRoutes by hostname; the tunnel is its only caller.
PostgreSQL, Redis, NATSData layerThe three things the applications actually need, with strict network rules around them.
SeaweedFSS3-compatible storageBuckets with one identity each, so an app or an agent only sees its own.
Prometheus, Grafana, Loki, TempoMetrics, dashboards, logs, tracesThe standard open stack, sized to leave room on one node.
FreeLLMAPIAI gatewayOne endpoint that speaks both the OpenAI and the Anthropic format over a pool of free model keys.
HerdrAgent workspaceA terminal multiplexer where coding agents keep running after I disconnect.

Every row has a decision record in the repository: docs/adr.
